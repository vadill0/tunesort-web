# tunesort-web

React client for **tunesort**: browse your Spotify liked songs grouped into
genre playlists and rate songs and albums.

> Status: early development. This repository only contains the web client.
> The backend lives in [`tunesort-api`](https://github.com/vadill0/tunesort-api).

## Project scope and goals
See [SCOPE.md](https://github.com/vadill0/tunesort-api/blob/main/docs/SCOPE.md)
in the API repository.

## Stack
React · Vite · React Router · axios
